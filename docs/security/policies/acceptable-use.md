# Acceptable use (staff and contractors)

Last reviewed: 2026-11-09 · Owner: security officer · Review: yearly · Acknowledged by every
person with access, on joining and yearly (record in the internal repository)

1. Use company accounts only for company work; use MFA on every account that has it, and a
   password manager for all passwords.
2. Keep laptops encrypted, updated and locked when unattended. Report a lost or stolen device
   to the security officer immediately.
3. Do not copy customer data to personal devices, personal cloud storage, public AI tools or
   chats. Use customer data only for the support request or incident it belongs to.
4. Do not install unvetted software or browser extensions on devices with production access.
5. Never share credentials; never put secrets in code, commits, issues or messages.
6. Do not discuss vulnerabilities or incidents in public (the repository is public); write to
   security@zerosoft.ai.
7. Report anything suspicious (phishing, unexpected access prompts, odd production behavior)
   right away. Reporting in good faith is never punished.
8. Coding agents follow the same rules through `CLAUDE.md` / `AGENTS.md`.
