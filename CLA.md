## How to sign

When you open your first pull request, the CLA bot posts a comment with a link
to this document. Reply on the pull request with exactly:

```
I have read the CLA Document and I hereby sign the CLA
```

The bot records your GitHub username, user id, the pull request and the date
in the `cla-signatures` branch of this repository. If the check doesn't
update, comment `recheck`.
