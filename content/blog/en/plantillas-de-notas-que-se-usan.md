Evernote published a [complete guide to note-taking templates](https://evernote.com/learn/the-complete-guide-to-note-taking-templates) and several more on meetings and 1:1s. The core idea holds up: if every meeting starts with the same four headings, writing takes less effort and finding things later takes less too.

What usually happens is different. Someone downloads fifteen templates from a gallery, uses two, and the other thirteen clutter the picker. This post takes the short route: six templates, each with one clear job, and how to set them up in Notes, the zerosoft notes app.

## What makes a template good

A template earns its place if it meets three conditions:

1. **It has few headings.** Three to five. If you delete sections every time, the template is too big.
2. **It ends in an action.** The last section is a task list or a next step. A note with no exit is a dead file.
3. **It answers a question you keep asking.** "What was decided?", "How do I reproduce it?", "What happens this week?" If there is no repeated question, you don't need a template.

## The six templates

Notes ships with nine built in (meeting, 1:1, to-do list, journal, weekly plan, reading list, brief, decision and bug). These six cover most of what a small team does.

**1. Meeting notes.** Agenda, Notes and Action items. The built-in one already looks like this. Action items is a checklist: write who and when on the same line, for example `Lucia: send quote, Thursday`. For a fuller format with follow-up between meetings, read [meeting notes that end in tasks](/blog/notas-de-reunion-que-terminan-en-tareas).

**2. 1:1 notes.** Two columns, "Their topics" and "My topics", with Notes and Next steps below. One note per person per month works better than one per meeting: you read the whole thread at a glance.

**3. To-do list.** Today, This week and Later. It is the template you will repeat most, so pin the note you build from it.

**4. Decision record.** Context, options in a table with pros and cons, the decision and its consequences. Use it for any choice someone will question in six months: a vendor, a price, a tool.

**5. Bug report.** Summary, steps to reproduce, expected, actual and an environment table with browser, version and device. Handy when support writes the problem down before passing it to [Track](/products/track).

**6. Brief.** Problem, who has it, goals, non-goals, requirements and open questions. Writing it in half a page before you start saves meetings.

The other three (journal, weekly plan and reading list) are personal: keep the ones you use.

## How to use them in Notes

In the sidebar, under "New note", there is a **New from template** button. It opens a gallery with your own templates on top and the built-in ones below, plus a field to filter by name. Picking one creates the note in the filter you are currently in.

When a built-in template almost fits, don't edit it. Create a note from it, adjust it and save it under a different name.

## Saving your own

1. Build a note with the structure you want, with headings and empty lists.
2. Open the note's **More actions** menu and choose **Save as template**.
3. Name it for what it does, not how it looks: "Weekly sales meeting", not "Template 3".

You can rename or delete it later from the gallery. Your templates also show up when you search with Cmd+K.

A few limits worth knowing:

- Each person can save up to **100 templates**. At the cap, Notes asks you to delete one.
- **Attachments are not copied**: a file belongs to its note and is deleted with it. If your template carries a PDF, attach it again in each new note.
- Templates are personal. There is no team-shared gallery yet.
- The option does not appear on a locked note or while offline.

## A habit to keep them from piling up

Every template you create is a decision you make once. The cost comes later, when there are forty and nobody remembers which is which. A simple rule: before saving a new one, check the gallery for a similar one. Once a quarter, delete the ones you haven't used.

Combined with tags, templates organize with little effort: the meeting note is born with the client's tag and that's it. The [notebooks and tags system](/blog/organizar-notas-libretas-y-etiquetas) we described earlier works the same with or without templates.
