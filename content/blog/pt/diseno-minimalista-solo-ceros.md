A home do zerosoft.ai abre com um zero grande feito de zeros. Não tem carrossel de logos nem foto de banco de imagens.

O site está pronto assim. Cada uma dessas ausências é uma decisão, e todas seguem a mesma lógica do nosso modelo de negócio.

## O zero é o roadmap

Para nós, o zero não é um logo. É a especificação completa do produto:

- **Software a US$ 0.** Tudo o que construímos é open source. Baixe, audite, hospede. Custa zero porque bits custam zero.
- **Margem zero.** Se preferir que a gente rode para você, paga o que a nuvem cobra. Nem um centavo a mais. Nem um a menos.
- **Lock-in zero.** Seus dados e seu código saem quando você quiser. A porta não tem chave.

Quando o seu modelo de negócio cabe num único glifo, você não precisa de vinte slides para explicá-lo. O site inteiro é uma frase.

## Um zero feito de centenas de zeros

O zero do centro não é uma imagem. É uma composição: centenas de zeros pequenos, cada um um caractere, desenhando o contorno de um zero maior. E são interativos: aproxime o cursor e eles reagem, se afastam, voltam.

Existe uma razão técnica para isso. O software que fazemos funciona do mesmo jeito: peças simples, idênticas, auditáveis, que combinadas produzem algo com estrutura. Um redirect de 300 bytes. Uma linha num banco de dados. Uma query SQL que qualquer um consegue ler. Nada de mágica proprietária escondida num binário.

A interatividade também não é capricho. É a prova de que o mínimo não é o pobre. Com um único caractere tipográfico e um evento de mouse dá para construir algo que as pessoas tocam, movem e lembram. Isso é engenharia: resolver com menos.

## Preto, branco e uma única tipografia

O site não tem cor. Literalmente: dois valores, `#000` e `#fff`. Não é daltonismo corporativo. É uma postura.

A cor no design de SaaS é um sedativo. Os gradientes roxos, os verdes de "sucesso", os azuis de confiança: existem para que algo medíocre pareça premium. Nós não temos nada para sedar. O produto funciona ou não funciona, e o preto e branco é o jeito mais honesto de dizer isso: aqui não tem nada disfarçado.

A tipografia é monoespaçada. A dos terminais, dos diffs, dos logs. É a tipografia com que se constrói software, não com que se vende. Se você lê o nosso site com a mesma fonte com que lê o seu código, é porque falamos a mesma língua.

## Design como manifesto, não como decoração

A maioria dos sites de software é decoração: camadas de animações, ilustrações e depoimentos em cima de um produto que não basta. O nosso funciona ao contrário. O design *é* o argumento.

Menos coisas na tela significa menos coisas para carregar, menos coisas para quebrar, menos coisas rastreando você. A página pesa o que pesa um texto. Carrega instantaneamente em qualquer conexão. E não há um único pixel ali para convencer você de algo que os números não dizem.

O zero não é minimalismo de Pinterest. É um contrato: tudo o que prometemos cabe naquele símbolo. Software a US$ 0, margem zero, lock-in zero.

Se uma empresa tem coragem de colocar o próprio modelo de negócio na capa, num único caractere, no mínimo vale a pena ouvi-la.
