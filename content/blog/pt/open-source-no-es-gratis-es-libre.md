Existe uma confusão antiga no mundo do software: achar que open source significa "grátis". Em inglês resolveram com uma piada: free as in beer vs free as in freedom. Grátis como a cerveja, livre como a liberdade.

Para nós, a distinção não é filosófica. É a base de tudo.

## Grátis é um preço. Livre é um direito.

Quando algo é simplesmente grátis, você é um convidado. O dono pode mudar o preço amanhã, fechar o serviço, vendê-lo, encolher seu plano. Você já viveu isso: ferramentas gratuitas que começaram a cobrar, planos que diminuíram, features que mudaram para o tier enterprise.

Quando algo é livre — código aberto de verdade — você é o dono. Pode ler o código, auditá-lo, modificá-lo, rodá-lo onde quiser, para sempre, sem pedir permissão. Ninguém pode aumentar seu preço porque não há preço. Ninguém pode fechar a porta porque a porta é sua.

## Por que o open source sempre vence no longo prazo

O software proprietário degrada com o tempo: o fornecedor adiciona features que você não pediu para justificar aumentos, e o roadmap responde a investidores, não a usuários.

O open source evolui diferente. Os bugs são encontrados por milhares de olhos. As features são pedidas por quem usa a ferramenta todos os dias. Se o projeto original se desvia, a comunidade faz um fork e segue. Linux, Postgres, Redis, nginx: a infraestrutura do mundo já é open source. O que faltava era a camada que os usuários tocam.

## O lock-in é incompatível com a liberdade

Olhe o padrão do SaaS moderno: grátis para começar, confortável para ficar, impossível para sair. Seus dados entram fácil e saem num CSV incompleto, se você tiver sorte.

O open source inverte o poder. Se a nossa nuvem falhar, você leva o código e seus dados e roda em outro lugar. Isso não é uma ameaça: é o design. Ser fácil sair é exatamente o que nos obriga a ser bons.

## Então, como se sustenta?

Simples: o software é livre, a nuvem não. Rodar servidores custa eletricidade e máquinas reais. Se você quiser que rodemos para você — com login, backups e uptime — paga exatamente isso: a infraestrutura, ao custo. Sem margem sobre o software, porque o software já é seu.

Grátis é uma promessa que pode ser quebrada. Livre é um fato que não pode ser revogado.

Por isso dizemos que o software morreu: morreu o software que não era seu.
