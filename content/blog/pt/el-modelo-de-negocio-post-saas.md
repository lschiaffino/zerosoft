Todo modelo de negócio é a resposta a uma restrição. O SaaS foi a resposta a duas: distribuir software era difícil (tinha que ser instalado) e construí-lo era caríssimo (o investimento precisava ser recuperado). A assinatura resolvia as duas: a nuvem elimina a instalação, e o pagamento recorrente financia o desenvolvimento.

As duas restrições sumiram. Distribuir é abrir uma URL. Construir custa uma fração do que custava. E mesmo assim a assinatura continuou, como um hábito sem causa.

O que a substitui? Estes são os quatro modelos que vemos emergindo.

## 1. Open source + nuvem cobrada pelo uso

O software é livre e hospedar custa $0; quem prefere não operar servidores paga pelo uso da nuvem. É o modelo da zerosoft. A virtude: o preço fica perto do custo e dá para compará-lo com a tabela pública dos provedores. O defeito, para investidores: a margem é pequena por desenho.

## 2. Open source + serviços reais

A Red Hat provou isso décadas atrás: o software é livre, e você cobra pelo que os humanos fazem, suporte, consultoria, garantias, certificações. Funciona porque cobra por trabalho real, não por copiar bits. A diferença para o SaaS: se você parar de pagar, perde o serviço, não o software.

## 3. Usage-based puro

Pagar exatamente pelo que você usa: requisições, minutos de computação, GB armazenados. Stripe e os provedores de nuvem vivem disso. É honesto na medida em que a métrica reflete o custo real; se corrompe quando a "unidade de uso" é inventada para maximizar a faturação (veja: assentos, "contatos de marketing", limites de API artificiais).

## 4. Compra perpétua (a volta)

Com o custo de desenvolvimento colapsando, volta a ser viável vender software de uma vez, como antes: US$ X, seu, com um ano de atualizações. Vários indies já vivem assim. Não escala para avaliações de trilhões, e essa é exatamente a razão pela qual beneficia os usuários.

## O que todos têm em comum

Nenhum deles pode cobrar por *copiar bits*. Esse é o fio condutor: quando o custo marginal é zero, qualquer preço acima de zero precisa de justificação, e "porque sempre foi assim" deixou de ser uma.

O SaaS não vai desaparecer de repente. Vai encolher para um serviço de hospedagem com software aberto por cima. É o modelo que escolhemos para a zerosoft.
